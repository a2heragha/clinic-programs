# clinic-programs

ملفات برامج العيادات الثلاث. كل حاسبة وكل هاتف يحدّث نفسه من مجلده هنا تلقائياً (`app/updater.py`).

| المجلد | العيادة |
|---|---|
| `azher/app` | عيادة أزهر وعلي |
| `younis/app` | عيادة د. مهند يونس (أونيكس) |
| `zak/app` | عيادة د. زكريا (باطنية) |

- أي دفع إلى `main` يصل إلى أجهزة العيادة في التشغيل التالي (أو خلال 6 ساعات).
- `config.remote.json` داخل مجلد عيادة: مفاتيح تُدمج في `config.json` على الأجهزة (مثل رابط Google جديد).
- لا توجد هنا أي بيانات مرضى ولا قواعد بيانات.
